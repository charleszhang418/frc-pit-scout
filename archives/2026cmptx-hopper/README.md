# Archive: FIRST Championship Houston 2026 — Hopper

Frozen snapshot of live scouting app data from Hopper division.

| File | Contents |
|---|---|
| `teams.csv` | Full Championship roster (all divisions) used by the app at Houston |
| `prescouting.json` | Pre-scout baseline (~73 teams with notes/tiers) |
| `pit-scout-baseline.json` | Pit + qual recovery snapshot (v2), exported ~2026-04-30 |

**Event context:** `2026cmptx` / Hopper  
**Do not overwrite these files.** They are the durable Hopper record in-repo.

To restore Hopper into a phone for review: copy a file back to the app root temporarily, or use **Data → Import JSON** / Import Pre-Scout.

Live off-season files live at the repo root again (`teams.csv`, `prescouting.json`, `pit-scout-baseline.json`).
